Розумний дім IoT: веб-сервер керування 4-канальним реле

Повна домашня автоматизація. Перетворіть мікроконтролер на автономний вбудований HTTP-веб-сервер: керуйте потужними побутовими приладами 220 Вольт (освітлення, кондиціонер, бойлер, насос) зі смартфона через локальну мережу Wi-Fi за допомогою оптично ізольованого 4-канального модуля реле.

⚡ Як безпечно комутувати 220 Вольт за допомогою 5 Вольт мікроконтролера?

Електромагнітне реле — це механічний вимикач, яким керує магніт. Коли пін Arduino видає сигнал, всередині маленького чорного чіпа оптопари PC817 спалахує інфрачервоний світлодіод. Світловий промінь падає на фототранзистор і замикає струм котушки електромагніта. Між небезпечною фазою побутової мережі 220V та мікроконтролером немає жодного металевого контакту — лише повітряний світловий промінь! Це називається гальванічною розв'язкою.

● АВТЕНТИЧНИЙ СКРІНШОТ TINKERCAD CIRCUITS З МОДУЛЕМ РЕЛЕ Клікніть для збільшення (Lightbox)

Керуючі входи IN1, IN2, IN3, IN4 підключено до цифрових пінів D4, D5, D6, D7. Реле спрацьовує при логічному нулі (Active LOW Trigger).

● ВЕКТОРНА СХЕМА FRITZING: КОМУТАЦІЯ НАВАНТАЖЕНЬ Гальванічна розв'язка

Клеми COM (Common) та NO (Normally Open) комутують розрив фазного дроту навантаження. Дріт нейтралі (N) іде безпосередньо до приладу.

Золоті правила роботи з реле та мережею 220V

1. Знеструмлюйте мережу перед монтажем!

Ніколи не торкайтеся гвинтових клем реле, коли мережевий шнур увімкнений у розетку 220V. Всі з'єднання виконуються тільки при вимкненому автоматичному вимикачі!

2. Ізолюйте зворотну сторону плати реле!

На звороті плати реле доріжки 220V оголені. Встановлюйте модуль тільки на діелектричні пластикові стійки всередині закритого монтажного короба.

● РОЗДІЛ 3 • ПОВНИЙ ВИХІДНИЙ КОД C++

Скетч вбудованого Web-сервера керування реле 

// SimpleArduino — Проєкт #09: Розумний дім IoT: веб-сервер керування 4-канальним реле
// Сумісно з ESP8266 (NodeMCU / Wemos) або Arduino з Ethernet/Wi-Fi шилдом

#include <ESP8266WiFi.h>
#include <ESP8266WebServer.h>

const char* ssid = "My_Home_WiFi";
const char* password = "WiFi_Password";

ESP8266WebServer server(80);

// Піни 4 каналів реле
const int RELAY_PINS[4] = {D1, D2, D5, D6};
bool relayStates[4] = {false, false, false, false};

void setup() {
  Serial.begin(115200);

  // Налаштування пінів реле (Більшість реле мають інверсну логіку: HIGH = вимкнено)
  for (int i = 0; i < 4; i++) {
    pinMode(RELAY_PINS[i], OUTPUT);
    digitalWrite(RELAY_PINS[i], HIGH); // Початковий стан — вимкнено
  }

  // Підключення до домашньої точки доступу Wi-Fi
  WiFi.begin(ssid, password);
  while (WiFi.status() != WL_CONNECTED) {
    delay(500);
    Serial.print(".");
  }

  Serial.println("");
  Serial.print("IP адреса веб-сервера: ");
  Serial.println(WiFi.localIP());

  // Маршрути веб-сервера
  server.on("/", handleRoot);
  server.on("/toggle", handleToggle);
  server.begin();
}

void loop() {
  server.handleClient(); // Обробка вхідних HTTP-запитів
}

void handleRoot() {
  String html = "<!DOCTYPE html><html><head><title>SimpleArduino Smart Home</title></head>";
  html += "<body style='font-family:sans-serif; text-align:center;'>";
  html += "<h2>Панель Розумного Дому</h2>";

  for (int i = 0; i < 4; i++) {
    html += "<p>Реле #" + String(i + 1) + ": <b>" + (relayStates[i] ? "УВІМКНЕНО" : "ВИМКНЕНО") + "</b> ";
    html += "<a href='/toggle?id=" + String(i) + "'><button>Перемкнути</button></a></p>";
  }

  html += "</body></html>";
  server.send(200, "text/html", html);
}

void handleToggle() {
  if (server.hasArg("id")) {
    int id = server.arg("id").toInt();
    if (id >= 0 && id < 4) {
      relayStates[id] = !relayStates[id];
      // Інверсна логіка Active LOW
      digitalWrite(RELAY_PINS[id], relayStates[id] ? LOW : HIGH);
    }
  }
  server.sendHeader("Location", "/");
  server.send(303);
}
● РОЗДІЛ 4 • ДІАГНОСТИКА ТА TROUBLESHOOTING

Матриця типових несправностей

✗

Реле працює навпаки: вмикається при LOW і гасне при HIGH

Це стандартна поведінка для 90% релейних плат (Active LOW). Світлодіод оптопари вмикається, коли вхід притягується до GND. Просто інвертуйте керування в коді: digitalWrite(pin, LOW) — це увімкнення!

✗

Світлодіод на реле горить, але лампа 220V не вмикається

Ви підключили провід до клем COM та NC (Normally Closed) замість COM та NO (Normally Open), або не подали окреме живлення 5V на контакт JD-VCC для спрацьовування електромагнітної котушки.

✗

При вмиканні потужного бойлера або мотора мікроконтролер підвисає

Електромагнітні завади (EMI)! Зніміть перемичку джампера JD-VCC / VCC на модулі реле. Подайте живлення котушок від окремого блоку 5V, залишивши з мікроконтролером лише оптичний зв'язок без спільного дроту живлення!

✗

Сервер недоступний за локальною IP адресою

Ваш домашній роутер використовує ізоляцію клієнтів (AP Client Isolation), або мікроконтролер підключився до мережі 5 ГГц (ESP8266 підтримує лише стандарт 2.4 ГГц).
