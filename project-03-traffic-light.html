🚦 Чому функція delay() заборонена в реальних світлофорах?

Уявіть, що мікроконтролер викликав delay(10000) для зеленого світла авто. У цей момент до переходу підходить пішохід і тисне кнопку виклику. Що станеться? Плата повністю паралізована: вона не може зчитати вхід, поки таймер не спливе. У цьому проєкті ми побудуємо неблокуючу систему, яка блискавично реєструє запит пішохода в пам\'яті й плавно перемикає фази через жовтий сигнал без аварій!

Прошивка скінченного автомата світлофора (FSM) 

// SimpleArduino — Проєкт #03: Розумний світлофор з кнопкою виклику пішохода
// Професійна архітектура на базі скінченного автомата станів (FSM) та millis()

// Піни світлофора для автомобілів
const int CAR_RED    = 10;
const int CAR_YELLOW = 9;
const int CAR_GREEN  = 8;

// Піни світлофора для пішоходів
const int PED_RED    = 7;
const int PED_GREEN  = 6;

// Пін тактової кнопки виклику переходу
const int BUTTON_PIN = 2;

// Перелік логічних фаз дорожнього руху (FSM States)
enum TrafficState {
  STATE_CAR_GREEN,      // Зелений для авто, червоний пішоходам
  STATE_CAR_YELLOW,     // Жовтий попереджувальний для авто
  STATE_ALL_RED_WAIT,   // Буфер безпеки: червоний усім учасникам
  STATE_PED_WALK,       // Зелений для пішоходів, авто стоять
  STATE_PED_FLASH       // Зелений пішоходам блимає (кінець фази)
};

TrafficState currentState = STATE_CAR_GREEN;
unsigned long stateStartTime = 0; // Мітка часу початку поточної фази
bool pedestrianWaiting = false;   // Прапорець наявності пішохода в черзі

// Часові інтервали фаз (у мілісекундах)
const unsigned long MIN_CAR_GREEN_TIME = 8000; // Мінімум зеленого для авто
const unsigned long CAR_YELLOW_TIME    = 2500; // Жовтий сигнал
const unsigned long ALL_RED_SAFETY     = 1500; // Захисний буфер (перехрестя пусте)
const unsigned long PED_WALK_TIME      = 7000; // Прохід пішоходів
const unsigned long PED_FLASH_TIME     = 3000; // Блимання перед вимкненням

void setup() {
  pinMode(CAR_RED, OUTPUT);
  pinMode(CAR_YELLOW, OUTPUT);
  pinMode(CAR_GREEN, OUTPUT);
  pinMode(PED_RED, OUTPUT);
  pinMode(PED_GREEN, OUTPUT);

  // Кнопка підключена на пін 2 та GND (внутрішня підтяжка до +5V)
  pinMode(BUTTON_PIN, INPUT_PULLUP);

  setInitialSignals();
  stateStartTime = millis();
}

void loop() {
  unsigned long now = millis();

  // 1. Постійно перевіряємо кнопку пішохода без затримок
  if (digitalRead(BUTTON_PIN) == LOW) {
    pedestrianWaiting = true; // Зафіксували запит у черзі
  }

  // 2. Логіка скінченного автомата
  switch (currentState) {
    
    case STATE_CAR_GREEN:
      // Якщо є пішохід і машини їхали вже достатньо часу
      if (pedestrianWaiting && (now - stateStartTime >= MIN_CAR_GREEN_TIME)) {
        digitalWrite(CAR_GREEN, LOW);
        digitalWrite(CAR_YELLOW, HIGH);
        currentState = STATE_CAR_YELLOW;
        stateStartTime = now;
      }
      break;

    case STATE_CAR_YELLOW:
      if (now - stateStartTime >= CAR_YELLOW_TIME) {
        digitalWrite(CAR_YELLOW, LOW);
        digitalWrite(CAR_RED, HIGH);
        currentState = STATE_ALL_RED_WAIT;
        stateStartTime = now;
      }
      break;

    case STATE_ALL_RED_WAIT:
      if (now - stateStartTime >= ALL_RED_SAFETY) {
        digitalWrite(PED_RED, LOW);
        digitalWrite(PED_GREEN, HIGH);
        currentState = STATE_PED_WALK;
        stateStartTime = now;
      }
      break;

    case STATE_PED_WALK:
      if (now - stateStartTime >= PED_WALK_TIME) {
        currentState = STATE_PED_FLASH;
        stateStartTime = now;
      }
      break;

    case STATE_PED_FLASH:
      // Блимаємо зеленим пішохідним кожні 400 мс
      digitalWrite(PED_GREEN, ((now / 400) % 2 == 0) ? HIGH : LOW);

      if (now - stateStartTime >= PED_FLASH_TIME) {
        digitalWrite(PED_GREEN, LOW);
        digitalWrite(PED_RED, HIGH);
        delay(1000); // Безпечний зазор перед стартом авто
        digitalWrite(CAR_RED, LOW);
        digitalWrite(CAR_GREEN, HIGH);

        pedestrianWaiting = false; // Очищуємо запит
        currentState = STATE_CAR_GREEN;
        stateStartTime = millis();
      }
      break;
  }
}

void setInitialSignals() {
  digitalWrite(CAR_GREEN, HIGH);
  digitalWrite(CAR_YELLOW, LOW);
  digitalWrite(CAR_RED, LOW);
  digitalWrite(PED_RED, HIGH);
  digitalWrite(PED_GREEN, LOW);
}

Матриця типових несправностей

✗

Світлофор перемикається без натискання кнопки

Пін кнопки встановлено як звичайний INPUT замість INPUT_PULLUP. Без внутрішньої підтяжки до +5V провід діє як антена і ловить наведення.

✗

Жовтий діод світиться одночасно із зеленим

Перевірте правильність розпіновки: катоди мають іти через резистори в шину GND, а аноди строго на D10, D9, D8. Переконайтеся, що ви викликаєте digitalWrite(CAR_GREEN, LOW) перед увімкненням жовтого.

✗

Зелений пішохідний не блимає перед вимкненням

У фазі STATE_PED_FLASH використовується формула (now / 400) % 2. Якщо замість now передати статичну змінну, блимання зупиниться.

✗

Один із світлодіодів дуже тьмяний

Ви помилково встановили резистор 10 кОм або 100 кОм замість 220 Ом. Для червоних, жовтих і зелених діодів нормальним номіналом є 220–330 Ом.
