Двоколісний автономний робот-ровер з уникненням перешкод

Справжній штучний інтелект на колесах. Скомпонуйте двоканальний Н-міст драйвера L298N для роздільного керування швидкістю коліс (ШІМ) та напрямком обертання двигунів, встановіть сонар на сервопривід для радарного сканування 180° та реалізуйте алгоритм виходу з глухих кутів.

🤖 Чому не можна підключати електродвигуни напряму до пінів Arduino?

Максимальний струм одного піна Arduino UNO — лише 40 міліампер (0.04 А). Електродвигун редуктора при старті або блокуванні споживає понад 1000 міліампер (1 А)! Якщо підключити мотор до піна мікроконтролера, внутрішні транзистори чипа ATmega328P миттєво вигорять із димком. Силовий модуль L298N працює як підсилювач струму: плата подає слабкі логічні сигнали керування, а драйвер бере потужний струм від батарей і крутить колеса вперед, назад або виконує розворот на місці!

Піни керування драйвером: ENA (D5 ШІМ), IN1 (D6), IN2 (D7), IN3 (D8), IN4 (D9), ENB (D10 ШІМ). Сервопривід сканера — D11.

● СИЛОВА МОНТАЖНА СХЕМА FRITZING Окреме живлення моторів

УВАГА: Земля батарей (GND) та земля Arduino (GND) обов'язково мають бути з'єднані разом для спільної точки відліку сигналів!

● СХЕМОТЕХНІКА ДРАЙВЕРА • ПРИНЦИП H-BRIDGE

Як 4 транзистори змінюють полярність напруги на клемах мотора?

Н-міст (H-Bridge) отримав назву через свою схему, що нагадує літеру «Н»: двигун розташований на горизонтальній перекладині, а по боках встановлені 4 потужні транзистори-ключі (Q1, Q2, Q3, Q4):

  • Рух вперед: Вмикаються ключі Q1 і Q4. Струм тече зліва направо через мотор.
  • Рух назад (реверс): Вмикаються ключі Q2 і Q3. Струм тече справа наліво!
  • Регулювання швидкості (ШІМ): Сигнал на піні ENA швидко вимикає верхні ключі, зменшуючи середню потужність обертання.

Прошивка автономної навігації робота 

// SimpleArduino — Проєкт #08: Автономний робот-ровер з уникненням перешкод
// Драйвер L298N + сонар HC-SR04 на сервоприводі SG90

#include <Servo.h>

// Піни драйвера L298N для лівого мотора
const int ENA = 5;  // ШІМ регулювання швидкості лівого мотора
const int IN1 = 6;  // Напрямок
const int IN2 = 7;

// Піни драйвера L298N для правого мотора
const int IN3 = 8;  // Напрямок
const int IN4 = 9;
const int ENB = 10; // ШІМ регулювання швидкості правого мотора

// Піни сонара та сервопривода
const int TRIG_PIN  = A2;
const int ECHO_PIN  = A3;
const int SERVO_PIN = 11;

Servo radarServo;
const int SPEED_NORMAL = 190; // Базова швидкість ШІМ (0..255)
const int DIST_STOP    = 25;  // Безпечна дистанція до перешкоди (см)

void setup() {
  pinMode(ENA, OUTPUT);
  pinMode(IN1, OUTPUT);
  pinMode(IN2, OUTPUT);
  pinMode(IN3, OUTPUT);
  pinMode(IN4, OUTPUT);
  pinMode(ENB, OUTPUT);

  pinMode(TRIG_PIN, OUTPUT);
  pinMode(ECHO_PIN, INPUT);

  radarServo.attach(SERVO_PIN);
  radarServo.write(90); // Центруємо сонар
  delay(1000);
}

void loop() {
  int distanceFront = measureDistance();

  if (distanceFront > DIST_STOP) {
    // Шлях вільний — крутимо колеса вперед
    moveForward(SPEED_NORMAL);
  } else {
    // Перешкода! Зупиняємося і скануємо горизонт
    stopMotors();
    delay(200);

    // 1. Повертаємо сонар ліворуч (150 градусів)
    radarServo.write(150);
    delay(400);
    int distLeft = measureDistance();

    // 2. Повертаємо сонар праворуч (30 градусів)
    radarServo.write(30);
    delay(500);
    int distRight = measureDistance();

    // 3. Повертаємо сонар у центр
    radarServo.write(90);
    delay(250);

    // 4. Приймаємо рішення про маневр
    if (distLeft > distRight && distLeft > DIST_STOP) {
      turnLeft(SPEED_NORMAL, 350); // Поворот ліворуч
    } else if (distRight >= distLeft && distRight > DIST_STOP) {
      turnRight(SPEED_NORMAL, 350); // Поворот праворуч
    } else {
      // Глухий кут з обох боків — здаємо назад і розвертаємось
      moveBackward(SPEED_NORMAL);
      delay(400);
      turnRight(SPEED_NORMAL, 500);
    }
  }
}

int measureDistance() {
  digitalWrite(TRIG_PIN, LOW);
  delayMicroseconds(2);
  digitalWrite(TRIG_PIN, HIGH);
  delayMicroseconds(10);
  digitalWrite(TRIG_PIN, LOW);

  long duration = pulseIn(ECHO_PIN, HIGH, 25000);
  if (duration == 0) return 300;
  return duration * 0.0343 / 2;
}

void moveForward(int speed) {
  analogWrite(ENA, speed);
  analogWrite(ENB, speed);
  digitalWrite(IN1, HIGH);
  digitalWrite(IN2, LOW);
  digitalWrite(IN3, HIGH);
  digitalWrite(IN4, LOW);
}

void moveBackward(int speed) {
  analogWrite(ENA, speed);
  analogWrite(ENB, speed);
  digitalWrite(IN1, LOW);
  digitalWrite(IN2, HIGH);
  digitalWrite(IN3, LOW);
  digitalWrite(IN4, HIGH);
}

void turnLeft(int speed, int durationMs) {
  analogWrite(ENA, speed);
  analogWrite(ENB, speed);
  digitalWrite(IN1, LOW);  // Ліве колесо назад
  digitalWrite(IN2, HIGH);
  digitalWrite(IN3, HIGH); // Праве колесо вперед
  digitalWrite(IN4, LOW);
  delay(durationMs);
  stopMotors();
}

void turnRight(int speed, int durationMs) {
  analogWrite(ENA, speed);
  analogWrite(ENB, speed);
  digitalWrite(IN1, HIGH); // Ліве колесо вперед
  digitalWrite(IN2, LOW);
  digitalWrite(IN3, LOW);  // Праве колесо назад
  digitalWrite(IN4, HIGH);
  delay(durationMs);
  stopMotors();
}

void stopMotors() {
  analogWrite(ENA, 0);
  analogWrite(ENB, 0);
  digitalWrite(IN1, LOW);
  digitalWrite(IN2, LOW);
  digitalWrite(IN3, LOW);
  digitalWrite(IN4, LOW);
}
● РОЗДІЛ 4 • ДІАГНОСТИКА ТА TROUBLESHOOTING

Матриця типових несправностей

✗

Одне колесо крутиться вперед, а інше назад при русі прямо

Мотори встановлені симетрично на лівому та правому борту шасі. Переверніть контакти підключення проводів одного з двигунів у клемнику драйвера L298N (поміняйте місцями OUT1 та OUT2).

✗

Робот починає рух і одразу зупиняється або перезавантажується

Спільна шина живлення! Ви спробували живити мотори від 5V піна Arduino або старої крони 9V (яка має великий внутрішній опір). Використовуйте два акумулятори 18650 напряму на силову клемму L298N і обов'язково об'єднайте заземлення GND батарей та Arduino!

✗

Мотори пищать, але колеса не крутяться

Занадто низьке значення ШІМ (наприклад, analogWrite(ENA, 80)). Для подолання сили тертя редуктора TT-моторів мінімальне пускове значення ШІМ становить не менше 150–170.

✗

Робот не бачить вузькі ніжки столів або чорні плінтуси

Кут охоплення ультразвукового променя сонара становить близько 15°. Тонкі об'єкти відбивають звук під кутом і відлуння не повертається до мікрофона. Рекомендується збільшити частоту сканування вежі.
